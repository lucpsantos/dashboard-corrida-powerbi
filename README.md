# Dashboard Corrida 15K
Projeto de análise de dados de uma corrida de 15 km, desenvolvido com Power BI e DAX, com foco na análise do perfil dos participantes e de seus resultados.

# Perguntas respondidas

1. Quantos atletas participaram da corrida?
2. Qual é a distribuição de participantes por gênero?
3. Qual faixa etária possui mais participantes?
4. Como os gêneros estão distribuídos por faixa etária?
5. Quais cidades possuem mais participantes?
6. Como os participantes estão distribuídos geograficamente?


# Principais insights
- 10.000 participantes registrados na base analisada.
- 56,78% masculino e 43,22% feminino.
- A faixa etária de 35 a 39 anos concentra o maior número de participantes, com 1.816 atletas.
- Taboão da Serra lidera o ranking de cidades, com 371 participantes.
- A distribuição geográfica permite visualizar a concentração de atletas nas diferentes regiões do Brasil.

# Dashboard:
Perfil dos participantes
Análise demográfica e geográfica dos participantes.
